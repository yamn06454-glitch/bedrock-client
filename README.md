# Bedrock Client

لانشر خاص لماين كرافت بيدروك على أندرويد — مبني من الصفر، بدون لانشر جاهز.
يشغّل **نسختك الأصلية** من Google Play داخل اللانشر ويضيف فوقها ميزات.

## الميزات
| الميزة | الوصف |
|---|---|
| 🔍 زوم | حقيقي (يقرّب العالم بس، الـHUD ما يتكبر) أو رقمي. ضغط مطوّل أو تشغيل/إيقاف، قوة 1.5x–10x، حركة ناعمة |
| ← زر رجوع | زر عائم يرسل Back للعبة |
| 🖥️ HUD | FPS، ساعة، بطارية، رام، مدة اللعب، نص مخصص، كروس هير — لكل عنصر: تشغيل/إيقاف، لون (ومنها رينبو)، حجم، خلفية، ومكان بالسحب |
| ⟳ إعادة تشغيل | زر في شاشة التحميل يعيد تشغيل اللعبة (ومن القائمة بأي وقت) |
| 📷 لقطة شاشة | تنحفظ في الصور/BedrockClient |
| ⚡ معدل تحديث | يطلب أعلى Hz تدعمه الشاشة (90/120) |
| 🔒 حماية | يرفض النسخ غير الأصلية (لازم تكون مثبتة من Google Play) |

كل شي يتطفى ويشتغل من الإعدادات في اللانشر، أو من زر ☰ داخل اللعبة.

## كيف يشتغل
- `LoaderFactory` (AppComponentFactory): في عملية `:game` يبني ClassLoader فيه كود اللانشر + كود ماين كرافت المثبتة + مكتباتها.
- `GameActivity` يرث `MainActivity` الحقيقية حق ماين كرافت، ويرجّع لها مواردها وملفاتها.
- `libclient.so` (C + ShadowHook): يعلّق على مكتبات الرسم في النظام (GLES/EGL/Vulkan) مو على ماين كرافت نفسها، عشان التحديثات ما تخرّب الكلاينت.
- الواجهة فوق اللعبة نوافذ فرعية للعبة نفسها، فما يحتاج صلاحية "الظهور فوق التطبيقات".

## البناء
كل push على `main` يبني APK عن طريق GitHub Actions وينشره في صفحة **Releases**.
